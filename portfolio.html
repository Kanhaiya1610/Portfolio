FRIDAY

Autonomous Stock Trading Agent (Deep RL)

  • Designed and trained custom DQN and LSTM-DQN agents in PyTorch for the Indian stock market, engineering a 15-dimensional state space (RSI, MACD, Bollinger Bands, Fibonacci levels, Residual Z-Score) with a composite reward function incorporating anti-churn penalties, drawdown minimization, and risk-adjusted returns.
  • Built an Evolutionary Arena Tournament system where multiple agent personas compete over rolling evaluation windows; top performers are selected via Sharpe Ratio and Total Return, then reproduced through Gaussian weight mutation.
  • Implemented a Universal Multi-Asset Trainer using curriculum learning across 50+ NSE/BSE tickers with environment rotation per episode, enabling a single market-agnostic RL model to generalize across stocks and timeframes, with CUDA-accelerated parallel inference powering a Monte Carlo engine.
  • Integrated an LLM-augmented sentiment pipeline using Google Gemini Flash to score Yahoo Finance RSS headlines into a continuous sentiment signal (–1.0 to +1.0) injected directly into the RL agent's state vector, with a 30-minute cache and multi-key fallback.

JLPT-RAG

Level-Adaptive Japanese Q&A

  • Built an end-to-end Retrieval-Augmented Generation system over a 400-chunk multilingual (English/Japanese) corpus spanning six anime franchises, MEXT/JASSO scholarship documentation, and JLPT vocabulary/grammar references.
  • Designed a query parser that extracts the requested JLPT proficiency level (N5–N1) from natural-language queries, and implemented multilingual semantic retrieval using Sentence-Transformers embeddings over a FAISS vector index.
  • Fine-tuned Llama 3.2 3B with 4-bit QLoRA (PEFT) to generate responses calibrated to the requested JLPT level, conditioning vocabulary and grammar complexity through level-specific system prompts.
  • Implemented a FAISS-based semantic cache with cosine-similarity thresholding, achieving a 100% hit rate on repeated/paraphrased queries and a 157x reduction in response latency.
  • Built a baseline-vs-fine-tuned evaluation harness combining a deterministic MeCab-tokenized JLPT-compliance scorer with an LLM-as-judge faithfulness checker.
